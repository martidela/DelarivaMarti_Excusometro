Excusómetro dela

La herramienta que analiza tus excusas

Todos tenemos una explicación para cada situación. El Excusómetro es una herramienta diseñada para analizar esas explicaciones y determinar hasta qué punto resultan creíbles, coherentes y justificadas.

¿Qué hacemos?

Introduce una excusa y deja que el sistema la analice. El Excusómetro evalúa diferentes criterios y genera un resultado que permite conocer su nivel de credibilidad.
